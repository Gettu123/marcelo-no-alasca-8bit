# Marcelo no Alasca — 8-Bit Ice Adventure

Jogo de plataforma 8-bit feito somente com HTML5 Canvas, CSS e JavaScript puro.

## Estrutura

- `index.html` — jogo completo
- `assets/avatar-reference.png` — imagem de referência do personagem
- `.nojekyll` — evita processamento desnecessário do Jekyll no GitHub Pages

## Controles

### PC
- ← / → ou A / D: andar
- Espaço / W / ↑: pular
- Enter: iniciar/continuar
- R: reiniciar a fase

### Celular
- botões ◀ ▶ ▲ na tela

## Objetivo

Atravesse as pedras de gelo até o iglu.
- Cair na água = perde uma vida.
- Encostar em um animal = perde uma vida.
- Cair fora das plataformas = perde uma vida.
- São 3 fases.
- O iglu é a chegada.
